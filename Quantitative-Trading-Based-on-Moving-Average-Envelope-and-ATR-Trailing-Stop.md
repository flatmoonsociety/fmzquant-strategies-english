## Overview
The name of this strategy is "MADEFlex", which stands for "Flexible quantitative trading strategy based on moving average envelope and average true range trailing stop loss". This strategy combines the Moving Average Envelope indicator and the Average True Range Trailing Stop mechanism to achieve a flexible and controllable quantitative trading solution.
## Strategy Principle
The core of this strategy is the Moving Average Envelope (MADE) indicator. The MADE indicator forms upper and lower rails by multiplying the exponential moving average (EMA) of the displacement by a percentage factor. When the price breaks through the upper band, a sell signal is generated; when the price falls below the lower band, a buy signal is generated. This strategy combines the MADE indicator with the Average True Range (ATR) trailing stop mechanism. ATR trailing stop loss sets the stop loss position at several times the ATR value to achieve flexible tracking of the stop loss line. This can avoid unnecessary stop losses and lock in already realized profits.
Specifically, the MADE indicator contains three parameters: period, upper track percentage perAb, and lower track percentage perBl. Period Period determines the period length of EMA. The amplitude of the upper and lower rails from the EMA is controlled by a percentage factor. The ATR trailing stop loss part is mainly set through the ATR period nATRPeriod and the ATR multiple nATRMultip. When the price exceeds the stop loss line of the previous K line, adjust the stop loss line to the price minus the fixed ATR loss; when the price is lower than the stop loss line of the previous K line, adjust the stop loss line to the price plus the fixed ATR loss.
Finally, buy and sell signals are generated by combining the MADE indicator signal and ATR trailing stop loss condition filtering. Reverse operation can be achieved through the reverse transaction input switch reverse.
## Advantage Analysis
The MADEFlex strategy offers the following advantages:
1. Combined with indicator signals and stop loss mechanism, it is more reliable. The MADE indicator itself is prone to producing false signals. Combined with ATR trailing stop loss, some noise can be effectively filtered out.
2. Rich adjustable parameters and flexible control. The parameters of the MADE indicator and the ATR parameters can be adjusted to control the quantity and quality of signals.
3. Support reverse operation. Reverse trading can be performed through the reverse switch to enrich strategy application scenarios.
4. Visual stopper is intuitive. By drawing the stop loss line, you can intuitively judge the stop loss effect.
## Risk Analysis
The MADEFlex strategy also carries the following risks:
1. Improper MADE indicator parameters may produce a large number of false signals. Careful testing is required to determine appropriate parameters.
2. ATR stop loss that is too loose may miss the stop loss opportunity. It is recommended to test to determine the appropriate ATR multiple.
3. Reverse operations are risky. Especially in highly volatile markets, reverse operations may increase the risk of losses. Need to be used with caution.
4. The absence of stop loss may result in greater losses. In extreme market conditions, no stop loss protection may cause greater losses.
## Optimization direction
The MADEFlex strategy can be optimized in the following directions:
1. Optimize MADE parameters and improve signal quality. Different cycle and percentage parameters can be tested to find a more reliable parameter combination.
2. Optimize ATR stop loss parameters to achieve better stop loss effect. You can test the ATR cycle and ATR multiples to determine a more appropriate combination.

// Moving Average Displaced Envelope. These envelopes are calculated 
// by multiplying percentage factors with their displaced expotential 
// moving average (EMA) core.
// How To Trade Using:
// Adjust the envelopes percentage factors to control the quantity and 
// quality of the signals. If a previous high goes above the envelope 
// a sell signal is generated. Conversely, if the previous low goes below 
// the envelope a buy signal is given.
//
// Average True Range Trailing Stops Strategy, by Sylvain Vervoort 
// The related article is copyrighted material from Stocks & Commodities Jun 2009 
//
// ATR TS used by filter for MADE signals.

strategy(title='Moving Average Displaced Envelope & ATRTS', shorttitle='MADE+ATR', overlay=true)
tradeDirection = input.string('Both', title='Trade Direction', options=['Both', 'Long', 'Short'])
Price = input(title='Source', defval=close)
Period = input.int(defval=9, minval=1)
perAb = input.float(title='Percent above', defval=.5, minval=0.01, step=0.1)
perBl = input.float(title='Percent below', defval=.5, minval=0.01, step=0.1)
disp = input.int(title='Displacement', defval=13, minval=1)

nATRPeriod = input(15)
nATRMultip = input(2)
useATR = input(false, title='ATR Filter')
reverse = input(false, title='Trade reverse')

longAllowed = tradeDirection == 'Long' or tradeDirection == 'Both'
shortAllowed = tradeDirection == 'Short' or tradeDirection == 'Both'
pos = 0
sEMA = ta.ema(Price, Period)
top = sEMA[disp] * ((100 + perAb) / 100)
bott = sEMA[disp] * ((100 - perBl) / 100)

xATR = ta.atr(nATRPeriod)
xHHs =ta.sma(ta.highest(nATRPeriod), nATRPeriod)
xLLs =ta.sma(ta.lowest(nATRPeriod),nATRPeriod)
nSpread = (xHHs - xLLs) / 2
nLoss = nATRMultip * xATR
var xATRTrailingStop = 0.0
xATRTrailingStop := close > nz(xATRTrailingStop[1], 0) and close[1] > nz(xATRTrailingStop[1], 0) ? math.max(nz(xATRTrailingStop[1]), close - nLoss) :
     close < nz(xATRTrailingStop[1], 0) and close[1] < nz(xATRTrailingStop[1], 0) ? math.min(nz(xATRTrailingStop[1]), close + nLoss) : 
     close > nz(xATRTrailingStop[1], 0) ? close - nLoss : close + nLoss

ATRLong = close > xATRTrailingStop ? true : false
ATRShort = close < xATRTrailingStop ? true : false

iff_1 = close > top ? 1 : pos[1]
pos := close < bott ? -1 : iff_1
iff_2 = reverse and pos == -1 ? 1 : pos
possig = reverse and pos == 1 ? -1 : iff_2
clr = strategy.position_size
if possig == 1 
    if longAllowed and ATRLong
        strategy.entry('Long', strategy.long)
    else
        if ATRLong or strategy.position_size > 0
            strategy.close_all()
if possig == -1 
    if shortAllowed and ATRShort
        strategy.entry('Short', strategy.short)
    else    
        if ATRShort or strategy.position_size < 0
            strategy.close_all()
if possig == 0
    strategy.close_all()
    
plot(xATRTrailingStop[1], color=color.blue, title='ATR Trailing Stop')
barcolor(clr < 0 ? #b50404 : clr > 0 ? #079605 : #0536b3)
