#### Overview
This strategy is an intelligent trading system based on institutional order flow, which predicts potential price reversal points by identifying order blocks (Order Blocks) in the market. The system adopts a dynamic warehouse management plan and optimizes position management through three levels of target positions to maximize returns. The core of the strategy is to capture the price traces generated by institutional trading behavior and identify important price levels through statistical analysis of high and low points.
#### Strategy Principle
The strategy is based on several key elements:
1. Order block identification - Use a 20-period lookback window to identify buy and sell order blocks by analyzing candlestick patterns. A buy block is confirmed by the previous bearish candle and the current bullish candle, and the reverse is true for a sell block.
2. Trading time control - limit trading to the main trading hours of 09:30-16:00, avoiding the more volatile opening and closing periods.
3. Entry logic - When the price breaks through the buy order block and is within the trading period, a long position is opened, and when the price breaks through the sell order block, a short position is opened.
4. Split warehouse management - adopt a three-tier warehousing plan of 50%-30%-20%, corresponding to the target levels of 0.5%, 1.0% and 1.5% respectively.
#### Strategic Advantages
1. Intelligent order identification - through dynamic analysis of high and low points, accurately capture the key price points for large funds to open and close positions.
2. Risk dispersion - The three-layer warehouse design effectively disperses risks, which not only ensures safe profits, but also gives the trend sufficient room for development.
3. Time filtering - By limiting trading time, periods of greater market volatility are avoided and the stability of trading is improved.
4. Visual support - The strategy provides clear visualization of order blocks, making it easier for traders to understand the market structure.
#### Strategy Risk
1. False breakthrough risk - Multiple false breakthrough signals may occur in sideways markets, and it is recommended to filter them in combination with volatility indicators.
2. Impact of slippage - In a market with insufficient liquidity, splitting positions and taking profits may face the impact of slippage. It is recommended to appropriately adjust the target distance.
3. Trend dependence - The strategy performs better in trending markets, but may produce frequent transactions in volatile markets.
#### Strategy optimization direction
1. Volatility adaptive - It is recommended to introduce the ATR indicator to dynamically adjust the target percentage according to market fluctuations.
2. Order flow analysis - it can be combined with transaction volume analysis to increase the confirmation of order blocks.
3. Dynamic time window - Consider dynamically adjusting the lookback period based on market conditions to improve strategy adaptability.
4. Enhanced risk control - Add maximum drawdown limit and daily loss limit to improve the robustness of the strategy.
#### Summary
This strategy builds a complete trading system through institutional order flow analysis and dynamic warehouse management. Through the identification of order blocks and multi-level take-profit settings, opportunities for large capital operations are captured and effective risk control is achieved. It is recommended that traders pay attention to the selection of market environment in real trading and adjust parameter settings according to specific circumstances.

//@version=6
strategy("Institutional Order Flow Strategy", overlay=true)

// Input settings
inputSession = input("0930-1600", "Trading Session") // Trading session
lookbackPeriod = input.int(20, "Order Block Lookback Period", minval=1) // Lookback for Order Blocks
target1Pct = input.float(0.5, "Target 1 (% move)", step=0.1, minval=0.1) // First profit target
target2Pct = input.float(1.0, "Target 2 (% move)", step=0.1, minval=0.1) // Second profit target
target3Pct = input.float(1.5, "Target 3 (% move)", step=0.1, minval=0.1) // Third profit target

// Order Block identification
highestHigh = ta.highest(high, lookbackPeriod)
lowestLow = ta.lowest(low, lookbackPeriod)
orderBlockBuy = ta.valuewhen(close[1] < open[1] and close > open, highestHigh, 0)
orderBlockSell = ta.valuewhen(close[1] > open[1] and close < open, lowestLow, 0)

// Entry logic
inSession = true
longCondition = close > orderBlockBuy and inSession
shortCondition = close < orderBlockSell and inSession

// Strategy entries
if longCondition
    strategy.entry("Long", strategy.long)

if shortCondition
    strategy.entry("Short", strategy.short)

// Calculate targets for scaling out
longTarget1 = strategy.position_avg_price + strategy.position_avg_price * target1Pct / 100
longTarget2 = strategy.position_avg_price + strategy.position_avg_price * target2Pct / 100
longTarget3 = strategy.position_avg_price + strategy.position_avg_price * target3Pct / 100

shortTarget1 = strategy.position_avg_price - strategy.position_avg_price * target1Pct / 100
shortTarget2 = strategy.position_avg_price - strategy.position_avg_price * target2Pct / 100
shortTarget3 = strategy.position_avg_price - strategy.position_avg_price * target3Pct / 100

// Exit logic with scaling out
if strategy.position_size > 0
    strategy.exit("Target 1", from_entry="Long", limit=longTarget1, qty_percent=50)
    strategy.exit("Target 2", from_entry="Long", limit=longTarget2, qty_percent=30)
    strategy.exit("Target 3", from_entry="Long", limit=longTarget3, qty_percent=20)

if strategy.position_size < 0
    strategy.exit("Target 1", from_entry="Short", limit=shortTarget1, qty_percent=50)
    strategy.exit("Target 2", from_entry="Short", limit=shortTarget2, qty_percent=30)
    strategy.exit("Target 3", from_entry="Short", limit=shortTarget3, qty_percent=20)

// Visualize Order Blocks
plot(orderBlockBuy, "Order Block Buy", color=color.green, linewidth=2, style=plot.style_line)
plot(orderBlockSell, "Order Block Sell", color=color.red, linewidth=2, style=plot.style_line)
