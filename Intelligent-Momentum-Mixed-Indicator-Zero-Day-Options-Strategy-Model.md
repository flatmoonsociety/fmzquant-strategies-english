#### Overview
The Smart Momentum Hybrid Indicator Zero-Day Options Strategy Model is a short-term options trading system that combines a variety of technical indicators and is specifically designed for zero-day expiration options (0DTE). This strategy forms a multi-dimensional trading signal generation mechanism by integrating moving average dispersion (MACD), volume weighted average price (VWAP), relative strength index (RSI), and two exponential moving averages (EMA5 and EMA13) with different periods. This strategy aims to capture short-term trend changes in the market, screen high-probability trading opportunities through strict entry conditions, and use reversal signals to manage risks.
#### Strategy Principle
The Smart Momentum Hybrid Indicator Zero Day Options Strategy Model is based on the following core principles:
1. **Multi-indicator collaborative confirmation**: The strategy requires all four technical indicators to meet specific conditions at the same time before a trading signal can be generated, which greatly improves the reliability of the signal. Specifically:
   - MACD: Determine the direction of short-term momentum. When the fast line is above the slow line, it is bullish, otherwise it is bearish.
   - VWAP: As an important price reference, it determines the position of the current price relative to the volume-weighted average price of the day.
   - RSI: Measures the overbought and oversold state of the market, using the 7-period RSI, with 50 as the dividing line between long and short.
   - EMA crossover: Use 5-period and 13-period EMA to determine the direction of the recent trend.
2. **Logically rigorous signal system**:
   - Bullish conditions: MACD fast line is above slow line + price is above VWAP + RSI is above 50 + EMA5 is above EMA13.
   - Bearish conditions: MACD fast line below slow line + price below VWAP + RSI below 50 + EMA5 below EMA13.
3. **Reverse signal closing mechanism**: When a signal appears in the opposite direction to the position, the strategy will automatically close the position. This mechanism helps to stop losses in time and lock in profits.
4. **Fund Management**: The strategy defaults to using 10% of the account's funds for each transaction, which helps control risk exposure and achieve effective use of funds.

strategy("Pierre's 0DTE Option Strategy with MACD, VWAP, RSI, EMA5/13", overlay=true, initial_capital=100000, default_qty_type=strategy.percent_of_equity, default_qty_value=10)

// INPUTS for 0DTE parameters
rsiPeriod    = input.int(7, title="RSI Period (0DTE)")
rsiThreshold = input.int(50, title="RSI Threshold (0DTE)")
macdFast     = input.int(6, title="MACD Fast Length (0DTE)")
macdSlow     = input.int(13, title="MACD Slow Length (0DTE)")
macdSignal   = input.int(5, title="MACD Signal Smoothing (0DTE)")

// INDICATOR CALCULATIONS
[macdLine, signalLine, histLine] = ta.macd(close, macdFast, macdSlow, macdSignal)
vwapValue = ta.vwap(close)
rsiValue  = ta.rsi(close, rsiPeriod)
emaShort = ta.ema(close, 5)   // Faster EMA for quick moves
emaLong  = ta.ema(close, 13)  // Longer EMA for trend confirmation

// PLOT INDICATORS
plot(emaShort, color=color.blue, title="EMA5")
plot(emaLong, color=color.orange, title="EMA13")
plot(vwapValue, color=color.purple, title="VWAP")

// SIGNAL CONDITIONS FOR 0DTE
// A bullish (Call) signal is generated when:
// • MACD is bullish (macdLine > signalLine)
// • Price is above VWAP
// • RSI is above threshold
// • Short EMA is above long EMA
callCondition = (macdLine > signalLine) and (close > vwapValue) and (rsiValue > rsiThreshold) and (emaShort > emaLong)

// A bearish (Put) signal is generated when the opposite conditions hold
putCondition  = (macdLine < signalLine) and (close < vwapValue) and (rsiValue < rsiThreshold) and (emaShort < emaLong)

// EXECUTE STRATEGY ENTRIES
if callCondition
    strategy.entry("Call", strategy.long)
if putCondition
    strategy.entry("Put", strategy.short)

// OPTIONAL: Close positions on reversal signals
strategy.close("Call", when=putCondition)
strategy.close("Put",  when=callCondition)

// ADDITIONAL PLOTS
hline(0, title="Zero Line", color=color.gray)
plot(macdLine - signalLine, color=color.green, title="MACD Histogram")

// ALERT CONDITIONS
alertcondition(callCondition, title="Call Signal", message="Call Option Signal")
alertcondition(putCondition, title="Put Signal", message="Put Option Signal")
